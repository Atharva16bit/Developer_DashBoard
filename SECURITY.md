# Security Policy

## Supported Versions

The latest version on the main branch is the supported version.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not disclose sensitive details publicly through a GitHub issue.

Instead, contact the repository owner through GitHub:

https://github.com/Atharva16bit

Please include:

- A description of the vulnerability
- Steps to reproduce it
- Potential impact
- Any relevant screenshots or proof of concept

## Security Notes

Developer Dashboard is a client-side static application.

It does not intentionally store:

- API keys
- passwords
- authentication credentials
- private tokens
- server-side secrets

Tool information is loaded from 	ools.json and rendered in the browser.

External links are opened using 
oopener noreferrer where applicable.

Third-party services such as external forms, fonts, favicon providers, and listed AI tools are outside the security boundary of this repository.
